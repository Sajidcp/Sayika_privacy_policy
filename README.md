# Sayika Privacy Policy

Privacy policy webpage for Sayika, an app that helps people find job opportunities.

## Privacy policy page

The policy is published from `index.html` in this repository.

## GitHub Pages setup

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then click **Save**.
4. Once published, copy the website address shown there and enter it in your app console's **Privacy Policy URL** field.
